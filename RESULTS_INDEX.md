## Reproduce (commands)
```bash
# synthetic (fast): E2/E1/E3/E4/E4-EXTREME/E5 — see reports/ for each; then:
python experiments/disentangle_scale_grad.py          # Adam disentanglement  (results/disentangle/)
python experiments/sgd_disentangle.py                 # SGD disentanglement   (results/sgd_disentangle/)
python experiments/fusion_robustness.py               # fusion robustness     (results/fusion_robustness/)
# CREMA-D (needs cache in data/cremad/cache/; regenerate via experiments/cremad_extract.py from ../CREMA-D-full):
python experiments/cremad_train_scale.py              # H6 dose-response      (results/cremad/)
python experiments/cremad_disentangle.py              # real-data decomposition (results/cremad_disentangle/)
# UTD-MHAD (needs ../UTD-MHAD/{Depth,Inertial}; cache via experiments/utd_extract.py):
python experiments/utd_train_scale.py                 # utility-gated          (results/utd_mhad/)
```
Each script runs its autograd/data sanity gate first and refuses on failure. GPU (CUDA) required
(configs set `device.allow_cpu: false`). Seeds [0–4] fixed in configs. Raw media + feature caches are
gitignored (regenerable); manifests with absolute paths are gitignored.
